# 학습 진도

기록일: 2026-10-09

## 학습 방식

- 경영학 입문 수준으로 한국어로 설명합니다.
- 쉬운 정의 → 일상 예시 → 시험용 한 문장 순서로 진행합니다.
- 한 번에 하나의 개념을 다루고, 질문이 나오면 해당 개념을 먼저 설명합니다.

## 현재까지 공부한 내용

| 개념 | 확인된 상태 |
|---|---|
| PESTEL | 이해했다고 말함. 금리 상승을 경제(E) 요인으로 맞게 분류함 |
| 트레이드오프 | 정의와 공부 시간·품질 및 비용 예시를 설명함 |
| 비영리단체 | 수입을 얻을 수 있으며 이익 분배보다 목적사업을 우선한다는 점을 설명함 |
| 사단법인과 재단법인 | 사람과 재산을 바탕으로 하는 차이를 설명함 |
| 두 법인의 운영 재원 | 사단의 회비·후원·사업 수입, 재단의 재산 수입·추가 기부를 설명함 |

## 이어갈 지점

마지막 학습 질문은 “재단법인은?”으로, 재단법인의 운영 재원을 설명했습니다. 이후 다른 컴퓨터에서 이어가기 위해 GitHub 저장을 요청했습니다.

다음에는 사단법인·재단법인의 차이를 간단한 예시로 확인한 뒤 사용자가 원하는 다음 개념을 설명합니다. 아직 확인하지 않은 개념을 이해했다고 단정하지 않습니다.
