## 다른 컴퓨터에서 이어가기

저장소를 내려받아 Codex에서 폴더를 열고 아래처럼 요청합니다. ChatGPT에서는 학습 파일을 프로젝트에 업로드하거나 내용을 붙여 넣을 수 있습니다.

> AGENTS.md, notes/progress.md, notes/study-log.md를 읽고 경영학 공부를 이어가자. 한국어로 쉬운 뜻 → 일상 예시 → 시험용 한 문장 순서로 설명해줘.

학습 후 진도와 내용을 갱신하고 GitHub에 올립니다. 새 컴퓨터에서는 최신 파일을 내려받습니다.

이 저장소는 학습 대화를 요약한 파일을 보관합니다. 채팅 자체를 자동으로 동기화하거나 복원하지는 않습니다.
